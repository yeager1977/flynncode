# K8s Hub Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spoke laptops sync chats/config to a central full Flynncode server on k8s when reachable, keep working offline when not.

**Architecture:** Hub is the existing server image as StatefulSet+PVC with `SYNC_HUB_MODE=1` (serves `/flynncode-sync/*`, never pulls). Spokes keep one peer (=hub), pull hub-newer as today, plus a new push phase for spoke-newer chats via hub-authenticated writes. Blind-relay secrets by default.

**Tech Stack:** Bun + TypeScript, Effect v4 raw HttpRouter, Drizzle SQLite, mobile-gateway sync worker, k8s StatefulSet+PVC+Tailscale, bun:test.

## Global Constraints

- Work on current branch, never commit to `dev` directly.
- Poll 60s (`POLL_MS=60_000`), backoff 5min after 5 failures, batch 20, batch delay 1s.
- No `any`, no star or aliased imports, bind Effect services (`const store = yield* MachineSyncStore.Service`), snake_case Drizzle columns, prefer `const`/early returns, avoid `try`/`catch`.
- Secrets masked as `__flynncode_sync_secret__`, `server` block never sent, placeholders never land in files.
- Newest `time_updated` wins per whole chat, equal does nothing, busy either side skips, parents before children, tombstone TTL 30 days.
- Tests only from package dirs (`cd packages/mobile-gateway && bun test <path>`, `cd packages/flynncode && bun test <path>`). Typecheck `bun typecheck` in each touched package.
- No public HttpApi change: raw `/flynncode-sync/*` only, no `bun run generate`, no SDK rebuild.
- Commits `type(scope): summary`.

```ts
export type PushAction =
  | { type: "push"; id: string }
  | { type: "delete"; id: string; timeDeleted: number }
  | { type: "archive"; id: string; timeArchived: number }
  | { type: "skip"; id: string; reason: "local-busy" | "peer-busy" }

export function decidePush(input: { local: Manifest; hub: Manifest }): PushAction[] {
  const hub = new Map(input.hub.sessions.map((session) => [session.id, session]))
  const hubDeleted = new Map(input.hub.tombstones.map((tombstone) => [tombstone.id, tombstone.timeDeleted]))
  const out: PushAction[] = []
  for (const current of input.local.sessions) {
    const remote = hub.get(current.id)
    if (remote && remote.busy) { out.push({ type: "skip", id: current.id, reason: "peer-busy" }); continue }
    if (current.busy) { out.push({ type: "skip", id: current.id, reason: "local-busy" }); continue }
    if (!remote) {
      if (current.timeArchived !== null) continue
      out.push({ type: "push", id: current.id })
      continue
    }
    if (current.timeUpdated > remote.timeUpdated) out.push({ type: "push", id: current.id })
  }
  for (const tombstone of input.local.tombstones) {
    const remote = hub.get(tombstone.id)
    if (remote && tombstone.timeDeleted > remote.timeUpdated) out.push({ type: "delete", id: tombstone.id, timeDeleted: tombstone.timeDeleted })
    void hubDeleted
  }
  return out
}
```
