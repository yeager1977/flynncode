Creates a git worktree on a new branch and moves this session into it, so the work happens in isolation from the main checkout. Use it only when the user asks to work in a worktree. The branch is <prefix>/<name>, or <prefix>/session-<id> without a name. The user is asked to approve every worktree. From the next step on, every tool works in the worktree folder; the previous folder's files are no longer the working directory. Not available in sub-agents, and only one worktree at a time: call exit_worktree before entering another.
