Leaves the worktree this session entered with enter_worktree and moves the session back to the folder it came from. action "keep" leaves the worktree and its branch on disk. action "remove" deletes the worktree folder, but only when nothing would be lost (no uncommitted changes, and every commit merged, pushed or on another branch); the branch is kept. When something would be lost, the call is refused and lists it, and the session stays in the worktree. discard_changes: true deletes the worktree and its branch anyway, after the user approves the loss. Only call it with discard_changes when the user asked to throw the work away.
