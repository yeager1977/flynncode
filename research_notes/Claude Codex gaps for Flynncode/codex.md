# OpenAI Codex Agentic Coding Surfaces — Current as of Oct 8, 2026

> Scope: Codex CLI, Codex IDE extension, Codex web/cloud (chatgpt.com/codex + ChatGPT desktop/work/mobile), background tasks, integrations. Focus on agentic coding capabilities. All facts from official OpenAI docs (`developers.openai.com/codex` / `learn.chatgpt.com/docs`), Codex changelog/whats-new, and `openai/codex` GitHub repo.

## 0. TL;DR — surfaces and how they differ

- **Codex CLI**: local terminal agent (`codex`, `codex exec`, `codex resume`, `codex cloud`, `codex mcp`, `/model`, `/permissions`, `/review`, `/agent`, `/import`). Works against local repo, runs local tools, composes with scripts/CI. Install via `install.sh`/`install.ps1`, npm `@openai/codex`, Homebrew, or GitHub Releases. [CLI](https://developers.openai.com/codex/cli)
- **Codex IDE extension** (`openai.chatgpt` marketplace): VS Code, Cursor, Windsurf, VS Code Insiders, Xcode (as agent), JetBrains (AI Chat → Codex). Brings open files/selection/recent chats into prompt, inline diff review, delegate to cloud. Same `config.toml`/MCP config as CLI. [IDE](https://developers.openai.com/codex/ide)
- **Codex Cloud**: reusable published **cloud environments** (repos + deps + tools + network/secrets) → each task gets isolated workspace/VM. Start from web/desktop (`Work in > Cloud`) or mobile (`Codex`), or `codex cloud` from CLI, or Slack/Teams `@ChatGPT`, or GitHub `@codex`. Runs while computer asleep. [Cloud](https://developers.openai.com/codex/cloud) / [Cloud envs](https://developers.openai.com/codex/environments/cloud-environments)
- **ChatGPT desktop app (macOS/Windows/Linux preview)**: since 2026-07-09 Codex merged into ChatGPT desktop app; Codex keeps dedicated view alongside Chat/Work. Local projects, multi-folder, review pane, browser/computer use, scheduled tasks, pets/appshots, voice. [Changelog 2026-07-09](https://developers.openai.com/codex/changelog)
- **Mobile (ChatGPT iOS/Android)**: no local execution; start/guide/review Cloud tasks or remote tasks on connected Mac/Windows PC, approve commands, inspect diffs. QR pairing, worktrees, widgets, task search. [Mobile](https://developers.openai.com/codex/mobile)
- **Open source**: CLI + app-server + SDK components in `openai/codex` (Apache-2.0, ~128k stars, ~20k forks, ~12k commits as of Oct 2026). Repo dirs: `codex-rs`, `codex-cli`, `sdk`, `docs`. [GitHub](https://github.com/openai/codex)

## 1. Codex CLI — features and mechanics

### Install / auth
- macOS/Linux: `curl -fsSL https://chatgpt.com/codex/install.sh | sh`; Windows PS: `irm https://chatgpt.com/codex/install.ps1 | iex`; alt: `npm i -g @openai/codex`, `brew install --cask codex`, or binaries `codex-*-apple-darwin.tar.gz` / `codex-*-unknown-linux-musl.tar.gz`. Env `CODEX_INSTALLER_USE_RELEASES_OPENAI_COM=false` forces GitHub Releases. [Repo](https://github.com/openai/codex)
- `codex` → **Sign in with ChatGPT** (Plus/Pro/Business/Edu/Enterprise) recommended; API-key mode requires extra setup. [Repo](https://github.com/openai/codex) / [Auth](https://developers.openai.com/codex/auth)

### Interactive loop
- Explore/plan/edit/run in repo, steer active turn, inspect commands/diffs, `codex resume` to reopen recent/local chats. [CLI](https://developers.openai.com/codex/cli)
- `/model` or `codex --model gpt-6.1-sol` / `-m`; `/permissions` picker; `codex --image` for screenshots/diagrams; `codex --search` for live web search; `codex completion` for shell completions; editor via `VISUAL`/`EDITOR`. [CLI](https://developers.openai.com/codex/cli) / [Models](https://developers.openai.com/codex/models)
- `codex cloud`: browse active/completed chats, submit to configured env, apply result locally. [CLI](https://developers.openai.com/codex/cli)

### Non-interactive (`codex exec`)
- `codex exec "<prompt>"` streams progress to stderr, final message to stdout; `--json` → JSONL (`thread.started`, `turn.*`, `item.*`); `-o` writes final message; `--output-schema schema.json` for structured JSON; `--ephemeral` skips rollout persistence; `resume --last` / `resume <SESSION_ID>` for 2-stage pipelines; requires Git repo unless `--skip-git-repo-check`; stdin piping (`| codex exec "..."` or `codex exec -`). Default read-only sandbox; `--sandbox workspace-write` / `danger-full-access`; `--full-auto` deprecated; `--ignore-user-config`, `--ignore-rules`. [Non-interactive](https://developers.openai.com/codex/non-interactive-mode)
- CI pattern: use `openai/codex-action@v1` (Responses API proxy) not raw `OPENAI_API_KEY` in checkout jobs; split `generate_fix` (read-only + patch artifact) / `open_pr` (write) jobs. [Non-interactive](https://developers.openai.com/codex/non-interactive-mode)
- Auth in automation: `CODEX_API_KEY` scoped to Codex invocation; ChatGPT-managed `~/.codex/auth.json` in CI only on trusted runners, never public repos. [Non-interactive](https://developers.openai.com/codex/non-interactive-mode)

### Review in CLI
- `/review` presets: base-branch (merge-base), uncommitted (staged+unstaged+untracked), commit, custom instructions. Dedicated reviewer, no working-tree mutation; `review_model` in `config.toml` can differ from session model. [Review](https://developers.openai.com/codex/code-review)

### Other CLI notes
- `codex mcp add/list/login`, `/mcp` in TUI; `codex mcp` connects to external MCP servers (STDIO + Streamable HTTP). Old `codex mcp-server` / `codex-mcp-server` binary **deprecated 2026-08-24, removed 2026-09-05** — use **app-server**. [Changelog 2026-09-05](https://developers.openai.com/codex/changelog) / [MCP](https://developers.openai.com/codex/extend/mcp)
- `/import` imports Claude Code/Cursor setup + recent chats. [Changelog 2026-08-11](https://developers.openai.com/codex/changelog)
- `/init` creates project instructions (also in desktop app 26.609). [Changelog 2026-06-11](https://developers.openai.com/codex/changelog)
- CLI 0.146.0/0.147.0 (July/Aug 2026): named chats (`/new`, `/clear`), pinned threads, side conversations, temp forks, Agent Plugins manifests, workspace plugin publishing, `--approve-for-me`, Bedrock cached search + remote compaction. [Whats-new July 27–31 / Aug 3–7](https://developers.openai.com/codex/whats-new)

## 2. Codex IDE extension — features and differences vs CLI

- Install: marketplace `openai.chatgpt`; open via Codex icon or **Codex: Open Codex Sidebar**; Xcode/JetBrains have native integrations. [IDE](https://developers.openai.com/codex/ide)
- Why IDE: uses already-open files/selection/recent chats (`Use editor context`), review summary + focused diff in place, keep/follow-up in same chat. CLI is terminal-loop + scripts/CI; IDE is context-already-open + in-place review. [IDE](https://developers.openai.com/codex/ide)
- Delegate: local for fast iteration, **Connect Codex web** for longer tasks; chat stays available on return. [IDE](https://developers.openai.com/codex/ide)
- `/review` only when project is in Git repo; scopes: base-branch or uncommitted; `chatgpt.reviewDelivery=detached` for separate review chat. [Review](https://developers.openai.com/codex/code-review)
- Permissions control beneath composer (Ask/Approve-for-me/Full access/profiles); shares `~/.codex/config.toml` + MCP with CLI/desktop. [Sandbox](https://developers.openai.com/codex/sandboxing) / [MCP](https://developers.openai.com/codex/extend/mcp)
- Subagents: background-agent panel (when available) above composer — expand for status, stop all, open thread. [Subagents](https://developers.openai.com/codex/agent-configuration/subagents)
- Goal mode available in IDE/CLI/app (GA since May 2026). [Changelog 2026-05-21](https://developers.openai.com/codex/changelog)

## 3. Codex web / cloud / desktop — execution

### Cloud environments (current, non-legacy)
- Create on web/desktop: **Work in > Cloud → Select environment → Create environment** or **Settings > Codex Cloud > Environments**. Pick GitHub repos, **Get started** → Codex inspects, installs deps/tools, tests; supply missing access; **Save → Publish**. New tasks start from published filesystem; existing tasks keep own state; background repo refresh preserves caches. Edit → Republish for updates. [Cloud envs](https://developers.openai.com/codex/environments/cloud-environments)
- Env config: **Install script** + **Start skill**; **Environment variables** (direct) vs **Network secrets** (placeholder + proxy substitution for allowed HTTPS:443 domains); **Personal vault** per-user values; **Allow internet** (`Package managers` preset list incl. npm/Yarn, PyPI, crates, Go proxy, Maven/Gradle, Bazel, Ubuntu/Debian, `github.com` etc., or Custom/Unrestricted); **Tailscale VPN** (Reusable+Ephemeral key, IPv4, split-DNS/MagicDNS); **OIDC** to AWS/Azure (Enterprise, by request); share via **Privacy → workspace**. [Cloud envs](https://developers.openai.com/codex/environments/cloud-environments)
- VM sizes: Plus/Edu Plus 2vCPU/8GB/8GB disk; Pro/Business/Enterprise/Edu 4vCPU/16GB/32GB; saved VM recoverable 7 days after last turn/resume; larger/custom on Enterprise. Limitations (Oct 2026): no computer/browser use, no GitLab/self-hosted GHES in new Cloud (GitLab beta runs in Codex cloud per Aug 19 note — see §5). Repo skills available; personal local skills not synced. [Cloud envs](https://developers.openai.com/codex/environments/cloud-environments)
- **Legacy Cloud** still backs Code Review + Linear/GitHub integrations; deprecation planned. [Cloud envs](https://developers.openai.com/codex/environments/cloud-environments)

### Desktop app specifics
- Local projects (incl. **multi-folder** since 26.715, primary folder for Git/`AGENTS.md`/`config.toml` discovery), **review pane** (Unstaged/Staged/Commit/Branch/Last turn, multi-repo selector, stage/unstage/revert per diff/file/hunk, inline `+` comments), **PR Chat**, **Sites**, **artifacts viewer** (PDF/sheets/docs/slides), **integrated terminal** (multi-terminal), tray/menu-bar, multi-window. [Changelog 2026-04-16/2026-07-23](https://developers.openai.com/codex/changelog)
- Browser: in-app browser (local/public no-sign-in pages, comments on rendered page), Chrome/Edge/Brave/Opera/Vivaldi extension (tab mentions, background tabs, side chat except Opera), **Site tools (WebMCP)** (GPT-5.6 Sol/Terra only, not Luna/Enterprise/Edu), cloud browser sign-in (eligible plans, not Enterprise/Edu). **Developer mode** (full CDP, 26.609) ~2x faster browser use. [Changelog 2026-08-25/2026-06-11](https://developers.openai.com/codex/changelog)
- Computer use: macOS + Windows foreground (takes over), locked-use (short-lived auth, covered display, relock), per-app controls on Windows; requires Computer Use plugin; EEA/UK/CH rollout June 2026. [Changelog 2026-05-29/2026-06-16](https://developers.openai.com/codex/changelog)
- Appshots (`Cmd×2` macOS, `Alt×2` Windows): screenshot + available text from frontmost window. [Changelog 2026-05-21](https://developers.openai.com/codex/changelog)

## 4. Execution comparison

|  | CLI | IDE | Cloud/web | Mobile |
|---|---|---|---|---|
| Where runs | local machine, your tools | local, editor context | OpenAI-hosted VM per task | Cloud or connected host, no local exec |
| Sandbox | Seatbelt (macOS) / bubblewrap (Linux/WSL2) / Windows Sandbox (PS) / Linux sandbox (WSL2); `read-only` / `workspace-write` (default) / `danger-full-access` | same as CLI (shared config) | managed isolated env + workspace Agent Security + per-env domain/VPN/OIDC policy | inherits host policy |
| Approvals | `/permissions`, `on-request` (default) / `never`, reviewer `user` / `auto_review` | composer permission control | tool-specific + workspace policy; no local sandbox selector on web | approve commands on phone |
| Git | local checkout, worktrees | local checkout | checks out GitHub (GitLab beta), per-task workspace, commit/PR from review | browse nested repos, worktree mode remembered |
| Network | sandbox-gated; rules allowlist | same | allowlist + secrets proxy + egress IP feed | via host |

- Sandbox applies to spawned commands (`git`, package managers, test runners inherit boundaries). [Sandbox](https://developers.openai.com/codex/sandboxing)
- Linux/WSL2 prereq `bubblewrap` (`apt/dnf install bubblewrap`); AppArmor `bwrap-userns-restrict` notes for Ubuntu 24.04/25.04. [Sandbox](https://developers.openai.com/codex/sandboxing)
- Full access = `sandbox_mode=danger-full-access` + `approval_policy=never`; low-friction local automation = `workspace-write` + `on-request` (or flags `--sandbox workspace-write --ask-for-approval on-request`); `untrusted` approval policy retired. [Sandbox](https://developers.openai.com/codex/sandboxing)
- `writable_roots` extends writable dirs without removing sandbox; `rules` allow/prompt/forbid command prefixes. [Sandbox](https://developers.openai.com/codex/sandboxing)
- Auto-review (`approvals_reviewer=auto_review`, `--approve-for-me`): reviewer agent approves/denies/stops/times out eligible boundary crossings; does not expand sandbox. [Sandbox](https://developers.openai.com/codex/sandboxing) / [Changelog 2026-04-23](https://developers.openai.com/codex/changelog)

## 6. Code review (local vs PR)

Asking Codex to apply fixes re-enters sandbox/approvals. [Review](https://developers.openai.com/codex/code-review)

[Review](https://developers.openai.com/codex/code-review)

## 7. Memory / instructions / subagents / skills / hooks

- **AGENTS.md**: loaded once per run/session; Global `~/.codex/AGENTS.override.md` else `AGENTS.md` → project root→cwd walk (one file/dir: `AGENTS.override.md` > `AGENTS.md` > `project_doc_fallback_filenames`), root-down concat, 32KiB default (`project_doc_max_bytes`), skips empty. Verify via `codex --ask-for-approval never "Summarize..."`, audit via `log_dir`/`session-*.jsonl`. `CODEX_HOME` profiles. [AGENTS.md](https://developers.openai.com/codex/agent-configuration/agents-md)
- **Memories / Computer History / Chronicle**: opt-in memories (prefs, stacks, conventions); Computer History (macOS, Pro/Business/Enterprise; admin must enable; EEA/UK/CH from Aug 2026, off by default, requires Memories); Chronicle (Pro macOS research preview). [Changelog 2026-08-13/2026-08-20](https://developers.openai.com/codex/changelog)
- **Subagents**: parallel delegated agents return summaries (avoids context pollution/rot). Trigger: explicit (“spawn two agents…”) or `AGENTS.md`/skill request; Ultra proactively delegates. Built-ins `default`/`worker`/`explorer`; custom `~/.codex/agents/*.toml` or `.codex/agents/*.toml` (`name`+`description`+`developer_instructions` + optional `model`/`model_reasoning_effort`/`sandbox_mode`/`mcp_servers`/`skills.config`); `[agents]` globals (`enabled`, `max_concurrent_threads_per_session`, `default_subagent_model/reasoning_effort`, `interrupt_message`); inherit parent sandbox/permission mode (+ per-agent `sandbox_mode` override); CLI `/agent` + `o` to open approval thread, IDE background panel, app subagent threads. Token-heavy. Example: `gpt-6-luna/high` for scans, `gpt-6.1-sol/medium` for reviewer. [Subagents](https://developers.openai.com/codex/agent-configuration/subagents)
- **Skills vs Plugins**: skill = reusable instructions+resources (`@` in ChatGPT, `$` in Codex, `$skill-creator`/`@skill-creator` to author); plugin = installable bundle (skills + MCP servers + hooks + UI) from universal directory; share via marketplace sources (Business; Enterprise coming). Record & Replay (macOS + Computer Use; EU/UK/CH from July 31) turns demo into skill. [Skills & Plugins](https://developers.openai.com/codex/skills-and-plugins) / [Changelog 2026-06-18/2026-07-31](https://developers.openai.com/codex/changelog)
- **Hooks** (GA May 14 2026): `~/.codex/hooks.json` / `config.toml [hooks]` / repo `.codex/` (trusted only) / plugins / `requirements.toml` managed. Events: `PreToolUse`, `PermissionRequest`, `PostToolUse`, `Pre/PostCompact`, `UserPromptSubmit`, `SubagentStart/Stop`, `Stop`, `Interrupt`, `SessionStart/End`. Command + `mcp_tool` handlers; matchers on tool names; trust per-hash via `/hooks`; `--dangerously-bypass-hook-trust`; `[features] hooks=false` off; `allow_managed_hooks_only`. Background `async:true` (max 8/session). [Hooks](https://developers.openai.com/codex/hooks) / [Changelog 2026-05-14](https://developers.openai.com/codex/changelog)

## 8. MCP / integrations / extensibility

- Local clients (desktop/CLI/IDE) share `config.toml` (`~/.codex/` or trusted `.codex/`): **STDIO** (command/args/env/cwd) + **Streamable HTTP** (bearer/OAuth CIMD+DCR/ChatGPT-session, `bearer_token_env_var`, headers/helpers, timeouts, `enabled/disabled_tools`, per-tool `approval_mode`/`output_token_limit`). `codex mcp add <name> -- <cmd>` / `list` / `login`; TUI/IDE `/mcp` + Restart. `instructions` field (first 512 chars critical). Plugin-bundled MCP via `.mcp.json` (camelCase OAuth). Examples: OpenAI Docs, Context7, Figma local/remote, Playwright, chrome-devtools, Sentry, GitHub MCP. [MCP](https://developers.openai.com/codex/extend/mcp)
- Web: hosted plugin tools only (no local `config.toml`); **Plugins** tab; Site tools (WebMCP) for website-provided tools. [MCP](https://developers.openai.com/codex/extend/mcp)
- **App-server** (replaces `mcp-server`): JSON-RPC 2.0 over stdio (default) / WebSocket (`--listen ws://`, experimental) / Unix socket / `off`; powers VS Code extension; `thread/*`, `turn/*` (steer/interrupt/inject), `review/start`, `command/exec`, `model/list`, `skills/list`, `hooks/list`, `plugin/*`, `mcpServer/*`, `config/*`, `fs/*`; `experimentalApi` opt-in; remote TUI (`app-server --listen` + `codex --remote`) and Code Mode host (`--code-mode-host wss://`). Experimental, not for production. [App Server](https://developers.openai.com/codex/app-server)
- SDKs: **Codex SDK** for automation/CI (not app-server); Security CLI/SDK `@openai/codex-security@0.1.5` (bulk/CI/SARIF, Bedrock auth); GitHub Action `openai/codex-action`. [App Server](https://developers.openai.com/codex/app-server) / [Whats-new July 27–31](https://developers.openai.com/codex/whats-new)
